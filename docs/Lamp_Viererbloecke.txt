WORUM ES GEHT

  Die 84 Lampen haengen als 21 x 4 Matrix am Board: 21 'Gruppen' (Ausgaenge der
  74HC595-Kaskade = je eine ULN2003A-Zeile) mal 4 Strobes (Spalten SA/SB/SC/SD
  vom Aux-Board). FA-Control nummeriert:

      Nummer n = (Gruppe - 1) * 4 + Strobe        (n = 0 .. 83, Strobe A=0 .. D=3)

  Umgekehrt, im Kopf zu rechnen:

      Gruppe = n / 4 + 1  (ganzzahlig)      Strobe = n mod 4  ->  0=A 1=B 2=C 3=D

  Ein Viererblock = eine Gruppe = eine Zeile der Matrix = die vier Nummern
  4k, 4k+1, 4k+2, 4k+3. Nur INNERHALB eines solchen Blocks sagt die Hypothese
  aus Lamp_Refresh_Analysis.md Abschnitt 3.3 ein Vorgluehen voraus:

      leuchtet Lampe n  ->  Kandidaten sind ihre drei Blocknachbarn
      ganzer Block aus  ->  dort darf nichts glimmen

  Glimmt es dagegen gleichmaessig ueberall, unabhaengig von den Nachbarn, ist es
  Leckstrom und nicht der Zeilen/Spalten-Versatz.
